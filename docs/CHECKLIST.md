# Ручная проверка перед релизом / Manual release checklist

Проверять на чистой Windows 10/11 x64 и на рабочей машине. Для каждого пункта: «через VPN» = программа открывает сайты, [api.ipify.org](https://api.ipify.org) показывает IP сервера; «заблокировано» = программа не может выйти в сеть, IP провайдера нигде не светится.

## Установка
- [ ] `VpnPause-Setup-x.y.z.exe` ставится, служба `VpnPauseService` в состоянии Running, тип запуска Automatic.
- [ ] После установки открывается мастер: язык, адаптер (по умолчанию «Автоматически»), пресеты, проверка.
- [ ] Старая версия (PowerShell, ярлык в автозагрузке, `apps.txt`) удалена, список программ перенесён.
- [ ] Повторная установка поверх (обновление) сохраняет `config.json`.
- [ ] Служба зависит от BFE (`sc qc VpnPauseService` → DEPENDENCIES BFE). Новая установка — строгий режим включён.
- [ ] Удаление: служба удалена, `VpnPause.exe --remove-filters` отработал, интернет у всех программ есть.

## Amnezia
- [ ] Режим AmneziaWG (адаптер `AmneziaVPN`): VPN включён → ChatGPT/Claude/Cursor через VPN.
- [ ] Режим Xray (адаптер `tun2`): то же самое, без правки настроек (авто-адаптер).
- [ ] Отключить VPN в Amnezia → защищённые программы заблокированы за 1–2 секунды, остальные работают.
- [ ] Включить VPN обратно → программы снова в сети без перезапуска.
- [ ] Kill switch Amnezia включён и выключен — оба варианта работают.

## Другие VPN
- [ ] WireGuard (официальный клиент) — авто-адаптер находит туннель.
- [ ] OpenVPN / другой TAP/Wintun — выбрать адаптер вручную в настройках.
- [ ] Opera: встроенный «VPN» Opera — это браузерный прокси, а не адаптер; Opera без системного VPN блокируется (это ожидаемо).

## Сеть
- [ ] Wi-Fi ↔ кабель ↔ мобильная точка: блокировка держится, ложных разблокировок нет.
- [ ] IPv6 у провайдера есть: [test-ipv6.com](https://test-ipv6.com) в защищённом браузере не показывает IPv6 провайдера.
- [ ] «Разрешить локальную сеть» выкл — принтер/NAS из защищённой программы недоступны; вкл — доступны.
- [ ] Строгий режим: остановить службу (`sc stop VpnPauseService`) → защищённые программы остаются заблокированными; «Аварийно снять все фильтры» возвращает сеть.

## Безопасность
- [ ] Обычный пользователь (`runas /trustlevel:0x20000`, `tools\pipe-basic.ps1`): setConfig/setEnabled/clearFilters → `admin-required`, status/getConfig/releaseStuck работают.
- [ ] Окно без прав администратора: выключить защиту / сохранить список → запрос UAC; «Нет» → «Действие отменено», ничего не изменилось.
- [ ] Строгий режим, удалить фильтры извне (`tools\audit-admin.ps1`) → через ≤10 с в журнале «restoring them», фильтры на месте.
- [ ] Путь `\\server\share\x.exe` и сетевой диск не принимаются; исключение `a` или `helper` не принимается.
- [ ] Испортить `config.json` → служба берёт `.bak`; испортить оба → фильтры остаются, окно пишет «настройки повреждены».
- [ ] Загрузка ЦП службы и окна в покое < 0,5% одного ядра.

## Сон, перезагрузка
- [ ] Сон/гибернация с выключенным VPN → после пробуждения программы заблокированы до подключения VPN.
- [ ] Перезагрузка: служба стартует до входа пользователя, фильтры на месте до запуска Amnezia.

## Обновления программ
- [ ] Обновить Cursor (новая папка версии) — правило продолжает работать без правки.
- [ ] Обновить ChatGPT/Claude из Store (новая версия пакета) — правило работает.
- [ ] Claude Code: новая версия в `claude-code\<версия>\` — правило работает.

## Заморозка (опция)
- [ ] По умолчанию выключена.
- [ ] Включить → отключить VPN → через 5 секунд фоновые процессы программы приостановлены, окна и буфер обмена не трогаются, рабочий стол переключается.
- [ ] Через 120 секунд всё размораживается само.
- [ ] Ctrl+Alt+Shift+P и «Отпустить всё» мгновенно размораживают.
- [ ] Закрыть VpnPause при замороженных процессах (в т.ч. убить через диспетчер) → служба размораживает их в течение 30 секунд, даже если VPN так и не вернулся.

## Интерфейс
- [ ] RU/EN переключается без перезапуска.
- [ ] Иконка в трее: зелёная — защищено и VPN есть; красная — VPN нет, программы заблокированы; оранжевая — VPN нет и есть замороженные процессы; серая — защита выключена или служба недоступна (подсказка в тексте значка).
- [ ] Уведомления о пропаже/возврате VPN (можно выключить).
