# История

## 1.1.0 — 26 ноября 2026: аудит безопасности и надёжности

По итогам аудита (15 находок):
- **Пропажа фильтров.** Если фильтры удалял кто-то другой или перезапускалась BFE, служба этого не замечала до смены сети. Теперь каждые 5 с идёт быстрая сверка, раз в минуту — полная, и фильтры восстанавливаются. Служба зависит от BFE.
- **Только администратор меняет защиту.** Раньше любой интерактивный пользователь через канал мог выключить защиту. Теперь служба проверяет токен клиента; окно без прав запускает себя через UAC (`--admin`). Чтение и разморозка — всем.
- **Строгий режим по умолчанию** для новых установок.
- **Заморозка на аренде.** Окно продлевает аренду каждые 5 с; если оно упало или время вышло, служба размораживает процессы через ≤15 с, независимо от VPN. Размораживаются только полностью приостановленные процессы — свои паузы программ не трогаются.
- **Пути.** UNC, `\\?\`, сетевые диски не принимаются. Исключения — только имя exe или полный путь. Лимиты: 200 программ, 100 исключений, 2000 файлов на предфильтрацию.
- **Настройки.** Запись через временный файл с flush, резервная копия `.bak`; при порче обоих файлов фильтры остаются, окно пишет «настройки повреждены». Язык и уведомления хранятся у пользователя и не требуют UAC.
- **Папка данных.** Если `%ProgramData%\VpnPause` создал не администратор (или это ссылка), она переносится в сторону и создаётся заново с правильным владельцем.
- **Канал.** Служба создаёт канал как первый экземпляр (перехват имени невозможен), окно проверяет, что на том конце именно VpnPause.exe.
- **Публикация папкой** вместо single-file: .NET больше не распаковывает DLL во временную папку, куда мог писать кто-то ещё.
- **Новые exe.** Служба следит за папками программ и ставит фильтры до первого запуска; новые процессы проверяются без открытия каждого.
- **ЦП.** Статус сети кэшируется до события Windows о смене адресов или маршрута: служба и окно с ~2,5–5% ядра сошли до долей процента.
- Пресет «Git и SSH»; документированы DNS и `--remove-filters` при работающей службе.

## 1.0.0 — 26 ноября 2026: продукт

Переписано с нуля на C# (.NET 8): служба + окно + установщик. Причина — зависания системы в старой версии: в списке был Cursor, заморозка задевала около 60 процессов, включая владельцев окон и буфера обмена. Рабочий стол переставал переключаться, а при «мигающем» туннеле однажды всё осталось замороженным до утра.

Что изменилось:
- Главная защита теперь не заморозка, а WFP-фильтры на каждую программу: пока VPN есть — разрешено через адаптер VPN, нет — блок. Ничего не зависает, соединения просто не уходят мимо туннеля.
- Служба `VpnPauseService` работает от SYSTEM, окно общается с ней через именованный канал с ACL.
- Автоопределение VPN-адаптера: Amnezia меняет адаптер между `tun2` (Xray) и `AmneziaVPN` (AWG), ручная настройка больше не нужна.
- Строгий режим: фильтры переживают падение службы и перезагрузку.
- Заморозка оставлена опцией: выключена по умолчанию, задержка 5 с, предел 120 с, не трогает окна и буфер обмена, защита от повторного использования PID, служба размораживает «застрявшие» процессы.
- Пресеты: ChatGPT, Codex, Claude, Claude Code, Cursor, VS Code, Opera, Opera GX, Chrome, Edge, Firefox, Telegram.
- RU/EN, мастер первого запуска, установщик Inno Setup, удаление со снятием фильтров.
- Миграция: список из `apps.txt` переносится, ярлык старой версии в автозагрузке и старые правила брандмауэра (`VpnPause ChatGPT/Claude/Claude Code`, `chatGPT V`) удаляются.

Найденные по дороге баги:
- `FwpmGetAppIdFromFileName0` приводит к нижнему регистру только латиницу. Путь с кириллицей в профиле пользователя никогда не совпадал с тем, что видит ядро, — фильтры молча не работали. Теперь app id собирается с полным `ToLowerInvariant`.
- Повышенный `%TEMP%` приходит коротким именем (`C:\Users\75BD~1`), путь разворачивается через `GetLongPathNameW`.
- Корень диска (`D:\tool.exe`) раньше считался «папкой программы» и захватывал весь диск.
- WMI-подписка `Win32_ProcessStartTrace` в службе падала с «Неправильный параметр». Новые exe теперь ищутся опросом снимка процессов раз в 2 секунды, без WMI.
- Импорт старого `apps.txt` узнаёт пресеты: Claude Code больше не приезжает под именем `claude`.

Старая версия (PowerShell-сторож) в публичный репозиторий не входит.
