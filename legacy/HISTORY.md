# История

25 ноября 2026. Сторож собран вместо Kordon: тот замораживает выбранные программы, когда VPN отваливается, но с версии 1.3 это закрытая программа. Открытым остался только снимок 1.2.2. Свой сторож повторяет базу, не весь Kordon.

Сначала стояло только правило брандмауэра на Wi-Fi для ChatGPT. Оно выбрасывает пакеты, соединение умирает, и после возврата VPN программу приходится открывать заново. Заморозка процесса это соединение сохраняет, если пакет не успел уйти.

Дальше по ходу работы:

- список программ с полным путём, выбор из запущенных и через обзор, подсказки в окне;
- в списке ChatGPT, Claude (магазин Windows) и Claude Code (отдельный exe в `Claude-Data`);
- узнавание новой сборки Store по семейству пакета, а не по номеру папки;
- заморозка сразу по смене маршрута, в фоне;
- если сторож убит во время паузы, при старте с живым туннелем процессы отпускаются;
- правила брандмауэра на Wi-Fi для всех трёх программ. Старое правило `chatGPT V` снято;
- свой `VpnPause.exe` и значок. Автозапуск указывает на exe, не на PowerShell.

Не делалось и пока не нужно: проверка страны и внешнего IP, Telegram, закрытие программ через 20 секунд, отдельные правила на каждую страну. Брандмауэр остаётся страховкой на тот случай, когда пакет ушёл в Wi-Fi раньше заморозки: тогда соединение уже не восстановить, программу нужно открыть снова.
